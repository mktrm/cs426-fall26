{%- comment -%} Renders _data/schedule.yml as the course agenda. Walks every day from `start` to `end`, keeps the weekdays listed in `meets`, and assigns sessions to those days in order — skipping `holidays`, which get their own "No Class" row. Because dates are derived rather than stored, inserting a session shifts everything after it automatically. Homework comes from `homework` instead, matched by absolute date, so a release or deadline can fall on a day the class does not meet — such a day gets a row of its own with nothing but the homework labels. Date arithmetic: the day cursor is anchored at 12:00, not midnight. Adding 86400s from local midnight lands on 23:00 the *previous* day once the clocks change (Nov 1), which would silently shift every December date back a day. Noon leaves an hour of slack on both sides. Formatting: this include is expanded inside a Markdown page, so emitted HTML must start at column 0. Four spaces of indentation would make kramdown treat the whole agenda as a code block. Liquid tags may be indented; the hyphen whitespace controls strip their surrounding blanks. {%- endcomment -%} {%- assign sched = site.data.schedule -%} {%- assign epoch = sched.start | append: " 12:00:00" | date: "%s" | plus: 0 -%} {%- assign last = sched.end | append: " 12:00:00" | date: "%s" | plus: 0 -%} {%- assign span = last | minus: epoch | divided_by: 86400 -%} {%- assign dow0 = epoch | date: "%w" | plus: 0 -%} {%- assign total = sched.sessions | size -%} {%- assign idx = 0 -%} {%- assign week = -1 -%} {%- for offset in (0..span) -%} {%- assign now = offset | times: 86400 | plus: epoch -%} {%- assign iso = now | date: "%Y-%m-%d" -%} {%- assign dow = now | date: "%w" | plus: 0 -%} {%- assign hwdue = sched.homework | where: "due", iso -%} {%- assign hwout = sched.homework | where: "out", iso -%} {%- assign nhw = hwdue | size | plus: hwout.size -%} {%- assign classday = false -%} {%- if sched.meets contains dow -%}{%- assign classday = true -%}{%- endif -%} {%- comment -%}A day earns a row if class meets, or if homework lands on it.{%- endcomment -%} {%- unless classday or nhw > 0 -%}{%- continue -%}{%- endunless -%} {%- if idx >= total and nhw == 0 -%}{%- continue -%}{%- endif -%} {%- assign holiday = sched.holidays[iso] -%} {%- capture hwmarks -%} {%- for h in hwdue -%}HW{{ h.id }} Due {% endfor -%} {%- for h in hwout -%}HW{{ h.id }} Release {% endfor -%} {%- endcapture -%} {%- assign thisweek = offset | plus: dow0 | minus: 1 | divided_by: 7 -%} {%- if thisweek != week -%} {%- unless week == -1 -%}{%- endunless -%} {%- assign week = thisweek -%} {%- assign n = week | plus: 1 -%}
